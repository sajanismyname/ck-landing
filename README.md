# Connect Kisan (कनेक्ट किसान)

> **Empowering Farmers. Connecting Markets. Growing Together.**  
> A unified, human-centered agricultural platform built specifically for Nepali farmers, cooperatives, agro-input suppliers, bulk produce buyers, and agricultural knowledge contributors.

---

## 🎯 1. Project Goal & Vision

Agriculture in Nepal employs over 60% of the national workforce, yet grassroots farmers continue to face severe systemic challenges:
1. **Fragmented & Opaque Market Rates**: Lack of transparent daily wholesale pricing leaves farmers vulnerable to middlemen and broker cuts.
2. **Delayed Agronomic Advisory**: Traditional agricultural extension services are geographically constrained, turning preventable pest and disease outbreaks into severe crop losses.
3. **Counterfeit & Unverified Agri-Inputs**: Adulterated seeds, low-grade fertilizers, and unverified tools harm soil fertility and reduce harvest yields.
4. **Lack of Farm Traceability & Credit Access**: Smallholders struggle to create structured farm proposals for bank financing, insurance, or premium organic export certifications.

### The Connect Kisan Mission
**Connect Kisan** is designed to bridge these gaps by creating an all-in-one digital agriculture ecosystem that empowers Nepali farmers to **Farm Smarter, Sell Better, and Grow More**.

## 🚀 2. Core Capabilities & Section Breakdown

### 🧭 A. Header & Integrated Sidebar
- **Header**: Contains universal search for products, crops, and market prices, direct Bazar link, `नेपाली | EN` language toggle, Login, and Sidebar toggle.
- **Integrated Sidebar**:
  - **Desktop**: Persistent vertical navigation region (`w-64` expanded / `w-20` collapsed) that allows the main content to fluidly occupy the remaining space.
  - **Mobile**: Slide-over drawer inspired by eSewa's navigation pattern with a backdrop overlay, close controls, and locked background scroll.
  - **4 Core Destinations**:
    1. **Home** (`/`)
    2. **Farming Knowledge** (*Crops*, *Livestock*, *Rooftop/Terrace*, *Pest Control*, *Soil Health*, *Video Guides*)
    3. **Information** (*Kalimati Market Price*, *Regional Markets*, *Kheti Calendar*, *Weather Forecast*, *Directory*)
    4. **Contribute** (`https://connectkisan.com/en/contribution`)

## 🛠️ 4. Getting Started

### Prerequisites
- Node.js `18.18.0` or higher
- npm or yarn

### Installation
```bash
# Clone or navigate to the repository
cd ck

# Install dependencies
npm install
```

### Development Server
```bash
npm run dev
```
Open [http://localhost:3000](http://localhost:3000) with your browser to see the landing page.

### Production Build & Type Checking
```bash
# Run TypeScript compilation check
npm run typecheck

# Build optimized production bundle
npm run build

# Start production server
npm start
```
